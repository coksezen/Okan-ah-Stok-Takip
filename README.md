# StokCep
İki kullanıcı için ortak stok, barkod ve SKT takip PWA'sı.

Özellikler:
- E-posta/şifre ile kullanıcı girişi
- Ortak ürün ve stok verisi
- Kamera ile barkod okutma
- Lot/parti bazlı son kullanma tarihi
- Stok +1/-1 işlemleri ve hareket geçmişi tablosu
- 10 gün kala Web Push bildirimi
- iPhone/Android ana ekrana kurulum

Kurulum için `KURULUM.md` dosyasını takip et.
